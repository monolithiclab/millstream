# Naming: availability and rationale

Checked 2026-10-14. The platform's working name is Strand. This note checks it, proposes alternatives, and
recommends a shortlist. It is not a legal clearance: a trademark search in classes 9 and 42 (INPI, EUIPO, USPTO)
comes before any public use of the chosen name.

## What the name has to do

- Say "work flowing through stages", the platform's core idea: items moving along streams through actions.
- Work in English and French: the platform is sold as a European, model-agnostic alternative.
- Be distinctive in the AI-agent and data-pipeline space, where names collide constantly.
- Make a short CLI command (`<name> run pipeline.yaml`).
- Have a usable domain (`.dev`, `.app`, `get<name>.com` or `<name>hq.com`) and a free `monolithiclab/<name>` repo.

## Method

- **Domains:** registry RDAP for `.com` (Verisign) and `.dev` / `.app` (Google Registry), and WHOIS for `.io`
  (`whois.nic.io`). "Taken" means registered, not necessarily in use.
- **GitHub:** whether the bare account name exists, and the three most-starred repos matching the name.
- **Products:** web searches for software products and companies using the name.

Every bare `.com` and `.io` checked is registered, which is expected for dictionary words. The table below lists only
the variants that came back free.

## Rationales

### Strand (current working name)

- **For:** short, a good CLI command, and the metaphor of threads of work running side by side fits streams.
- **Against:** AWS released **Strands Agents** in May 2025, an Apache-2.0, model-agnostic SDK for building AI agents
  "from local development to deployment in production", used inside Amazon Q Developer and AWS Glue. It is the same
  audience, the same licence and almost the same pitch. Every search for "strand agents pipeline" would land on AWS,
  and the overlap invites confusion, or a trademark dispute with Amazon. `strand.com`, `.dev`, `.app`, `.io`,
  `getstrand.com` and `strandhq.com` are all registered.
- **Verdict:** drop it, and keep it only as the internal working name until the rename.

### Millrace

- **For:** the best metaphor of the set. A millrace is the channel that carries water to the wheel that does the
  work: a stream feeding actions.
- **Against:** `tim-osterhus/millrace` "turns repeatable, domain-agnostic workflows into graph-driven loops". It is
  an agentic workflow tool, active this week, the same idea under the same name.
- **Verdict:** drop.

### Sluice

- **For:** a sluice controls flow, as filter and review steps do.
- **Against:** the most crowded name in the set. SluiceCI is a CI/CD pipeline platform, a TypeScript streaming
  pipeline called Sluice advertises backpressure and exactly-once materialisation, and Sluice is also a workflow
  management app. Every domain variant is taken except `sluice.sh`.
- **Verdict:** drop.

### Flume, Weft, Heddle, Trame

All four are already taken in our space: Apache Flume is a data pipeline tool; Weft is an AI orchestration language
with about 2,000 stars; Heddle, by the same people, is a policy layer for MCP servers; Kitware's trame is a well-known
Python framework whose tagline is about weaving components. Dropped.

### Weir

- **For:** a weir regulates a river's flow without stopping it, a good image for backpressure and filtering. Short.
- **Against:** The Weir Group plc is a large listed engineering company with its own software products, so the
  trademark is strong in adjacent classes. Searches are polluted by "weird". Only `weirhq.com` and `weir.sh` are free.
- **Verdict:** weak.

### Lade

- **For:** the Scots word for a millrace, so it keeps the millrace metaphor; four letters.
- **Against:** obscure in English and French, and reads as German "load". `zifeo/lade` is an established CLI.
  Domains are all taken except `lade.sh`.
- **Verdict:** weak.

### Maillon

- **For:** "un maillon de la chaîne", a link in the chain: exactly what an action is in a pipeline. Free on GitHub in
  practice.
- **Against:** hard to pronounce in English ("my-yon"), and only `maillonhq.com` is free.
- **Verdict:** weak.

### Écluse (recommended)

- **Meaning:** a canal lock. A lock moves boats from one level to the next in controlled stages, holding them until
  the gate opens. That is a pipeline of steps with gates, including human review, which most names here miss.
- **For:**
  - Distinctive in software: the only conflicts are two small repos, one for dev environments for coding agents
    (11 stars) and one a package-registry proxy (5 stars). The web search found no product or company.
  - A French word that English speakers can read, which supports a European, sovereign positioning.
  - Good domains are free: `ecluse.app`, `getecluse.com`, `eclusehq.com`, `ecluse.sh`. `monolithiclab/ecluse` is
    free.
  - Six letters, a clean CLI command: `ecluse run pipeline.yaml`.
- **Against:**
  - The accent is dropped in code, domains and the CLI (`ecluse`); the brand can keep "Écluse".
  - English speakers will guess at the pronunciation ("ay-klooz").
  - `ecluse.com` and `ecluse.dev` are registered (the `.com` since 1999).
- **Verdict:** recommended, subject to the trademark search.

### Workmill

- **Meaning:** a mill for work. Raw items go in, processed results come out, and code, agents and people are the
  machinery.
- **For:**
  - Self-explanatory in English, with no pronunciation question.
  - The best domain availability of the set: `workmill.dev` (ideal for a developer tool), `workmill.app`,
    `getworkmill.com`, `workmillhq.com`, `workmill.sh`. GitHub account and `monolithiclab/workmill` are free.
- **Against:**
  - Workmill Inc. (New York) sells project management and team collaboration software at `workmill.com`, an
    adjacent category, so the trademark risk is real in class 42. Japan's WORK MILL is a workplace media brand.
  - "Mill" can read as "content mill" or "grind", which clashes with a premium positioning.
  - Eight letters for the CLI; an alias such as `wm` would be needed.
- **Verdict:** shortlist; strong if the trademark search on Workmill Inc. comes back narrow.

### Rouage

- **Meaning:** a gear or cog; "les rouages" are the inner workings of a machine or an organisation. Each action is
  a cog, and the platform is the mechanism.
- **For:** a familiar, pleasant French word with an obvious metaphor; nothing in the developer or AI space uses it;
  `rouagehq.com` and `rouage.sh` are free; `monolithiclab/rouage` is free.
- **Against:**
  - rouage.app is French software for vehicle maintenance. It's a different market, but the same country and
    probably the same trademark classes (9 and 42).
  - `rouage.com`, `.dev`, `.app` and `.io` are registered.
  - English speakers will not know the word.
- **Verdict:** shortlist, behind Écluse.

## Recommendation

1. **Écluse**: the most distinctive name in our space, a metaphor that covers gated stages and human review, and
   usable domains (`ecluse.app`, `getecluse.com`).
2. **Workmill**: the clearest in English with the best domains, if the existing Workmill Inc. trademark leaves room.
3. **Rouage**: a fallback with a strong French identity.

Next steps before renaming:

- Trademark searches for the chosen name at INPI, EUIPO and USPTO in classes 9 and 42.
- Register the domains and create `monolithiclab/<name>`.
- Rename the repo, the CLI and every `strand` reference in the spec in one commit.
