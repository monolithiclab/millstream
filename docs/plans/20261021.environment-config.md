# Environment configuration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One tagged struct is the environment configuration: defaults from tags, then `millstream.yaml`, then
`MILLSTREAM_*` variables, then flags; `millstream init environment` writes the default file; Compose and systemd
configure through variables.

**Architecture:** `internal/pipeline/environment.go` keeps `Environment` but as a tree of named section structs with
`yaml`/`env`/`default`/`doc` tags. A small reflection walker (new `internal/pipeline/envconfig.go`) applies defaults,
applies variables, and renders the default file; yaml.v3 decodes the file directly; `Validate` replaces the node
readers. The store and artifacts become one URL each (`store.dsn`, `artifacts.url`), libpq and AWS conventions doing
the rest.

**Tech Stack:** Go standard library, `go.yaml.in/yaml/v3`, pgx (`PG*` variables), Kong.

**Spec:** `docs/specs/20261021.environment-config-design.md`

## Global Constraints

- The product owner asked for less code than today: the new loader (struct, walker, Validate) must be shorter than the
  ~1000-line `environment.go` it replaces. Prefer deleting a feature's special case to supporting it.
- Variable name: `MILLSTREAM_` + the `env` tag segments of the path joined by `_` (`MILLSTREAM_UI_BASE_URL`).
- `store.dsn` default `sqlite://.millstream/millstream.db`; schemes `sqlite://`, `postgres://`, `postgresql://`; a
  password in the DSN is refused with a pointer to `PGPASSWORD`.
- `artifacts.url`: `file://<path>` or `s3://<bucket>[/<prefix>]`; S3 reads `AWS_ACCESS_KEY_ID`,
  `AWS_SECRET_ACCESS_KEY`, `AWS_REGION` (default `us-east-1`), `AWS_ENDPOINT_URL` through `Runtime.Env`.
- Client variables untouched: `MILLSTREAM_SERVER`, `MILLSTREAM_TOKEN`, `MILLSTREAM_COLOR`, `MILLSTREAM_SECRET_<NAME>`,
  `MILLSTREAM_LIVE`. `MILLSTREAM_NODE_TOKEN` is both the node's join token and `node.token`, on purpose.
- No compatibility code for the old keys (`store.sqlite`, `store.postgres`, `artifacts.local`, `artifacts.s3`).
- Lint is part of `make ci`; commits `type(scope): summary` with the session trailer
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; no push.
- Gates: agents run `make ci` and `make test-e2e PKG=<touched packages>` only; never full `make test-e2e`,
  `make soak` or `make test-times` (run once by the controller at the end).

## Review Focus

1. A relative path in a file named with `--env-file /etc/millstream/millstream.yaml` resolves against `/etc/millstream`;
   the defaulted `store.dsn` still resolves against the working directory. Test in Task 1.
2. A variable set to the empty string (`MILLSTREAM_LISTEN=`) counts as unset, as Compose's `${X:-}` produces it.
   Test in Task 1.
3. A typo'd variable (`MILLSTREAM_UI_BASEURL`) fails at startup naming the variable; `MILLSTREAM_SERVER` does not.
   Test in Task 1.
4. A wrong-typed value from a variable (`MILLSTREAM_NODE_EMBEDDED=maybe`) names the variable, not a YAML line.
   Test in Task 1.
5. Every line of the generated file, uncommented, parses. Test in Task 2.
