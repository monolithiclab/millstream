# M1 core engine: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Tasks use checkbox syntax.
> Each task is test-first: write the listed tests, see them fail, implement, see them pass, `make ci`, commit.

**Goal:** a single `millstream` binary that loads a pipeline package, validates it, and runs it on a laptop with
SQLite and an embedded node, surviving a `kill -9` at every boundary of every M1 atomic unit.

**Architecture:** one Go module. `internal/pipeline` parses and validates packages; `internal/expr` is the CEL
environment; `internal/schema` validates JSON and checks schema compatibility; `internal/store` is the log store with
a single writer loop applying atomic units; `internal/engine` schedules triggers, dispatches deliveries and tracks
runs; `internal/node` pulls deliveries over an in-memory transport and runs `exec` actions through
`internal/runtime/exec` speaking the JSON-lines protocol of `internal/protocol`; `internal/cli` is the Kong CLI. The
Go SDK is a separate module under `sdk/go`.

**Tech stack:** Go 1.27 (`go 1.27.0`, `toolchain go1.27.2`), Kong, go.yaml.in/yaml/v3, cel-go, modernc.org/sqlite,
robfig/cron/v3, santhosh-tekuri/jsonschema/v6. Lint and tooling per the `lab-go-app` skill (common.go.mk,
golangci-lint v2, govulncheck, tools/go.mod).

**Spec:** [platform design](../specs/20261014.platform-design.md), sections 4, 5, 6, 10.3, 13, 16 and 19 (M1 row).

## Global constraints

- Module path `github.com/monolithiclab/millstream`; SDK module `github.com/monolithiclab/millstream/sdk/go`, wired
  into the main module with a `replace` directive.
- Every key and multi-word value Millstream defines is lowerCamelCase in JSON and YAML (D18); SQL tables and columns
  are snake_case; metric names are Prometheus snake_case.
- Item ids: `hash(producing_step, out_stream, input_item_id, generation, key ?? output_index)`, hex SHA-256 truncated
  to 32 hex chars, prefixed `it_` (D9). Trigger item ids: `hash("trigger", name, key)`. Dead letters:
  `hash("dlq", dlq stream, origin delivery id, output id or "")`.
- Outputs publish on `done` only (D20); a delivery with more than one output must key all of them.
- All writes go through the single writer loop (D23); lease expiry uses the database clock.
- Logs: `log/slog` JSON on stderr with keys `pipeline`, `runId`, `step`, `itemId`, `deliveryId`, `attempt`, `node`;
  never log payload values (D27).
- No network in tests; tests use `t.Parallel()`, `-race`, table tests; crash tests build the binary once in
  `TestMain`.
- No customer names anywhere (AGENTS.md hard rule).

## Review focus

1. A crash between staging outputs and `done`: the retry must not publish twice nor lose outputs. Pinned by the
   crash suite (Task 11).
2. Two outputs of one delivery where one has no key: must fail as a protocol error, not silently collide (Task 7).
3. A cron firing missed while the engine was down: `catchup: latest` fires once, `all` fires each, `none` records
   skipped events (Task 9).
4. An action process that writes garbage on stdout, exits mid-delivery, or never answers: the delivery retries, the
   process is replaced, nothing is published (Task 8).
5. A run cancelled while a delivery is leased: its outputs are discarded and it ends `cancelled` with its cost
   (Task 7, Task 9).

## Store schema (SQLite, migration 1)

```sql
packages(hash TEXT PRIMARY KEY, bundle BLOB, created_at TEXT)
revisions(id INTEGER PRIMARY KEY, pipeline TEXT, package_hash TEXT, applied_at TEXT, state TEXT)
pipelines(id TEXT PRIMARY KEY, active_revision INTEGER, state TEXT)           -- active|paused|disabled
steps_state(pipeline TEXT, step TEXT, paused INTEGER, PRIMARY KEY(pipeline, step))
runs(id TEXT PRIMARY KEY, pipeline TEXT, revision INTEGER, trigger TEXT, kind TEXT, generation INTEGER,
     vars TEXT, state TEXT, started_at TEXT, settled_at TEXT, cost_usd REAL)
items(id TEXT PRIMARY KEY, pipeline TEXT, run_id TEXT, stream TEXT, step TEXT, key TEXT, parents TEXT,
      generation INTEGER, ts TEXT, payload TEXT, payload_hash TEXT)
deliveries(id TEXT PRIMARY KEY, pipeline TEXT, run_id TEXT, step TEXT, item_id TEXT, generation INTEGER,
      state TEXT, attempt INTEGER, lease_owner TEXT, fencing_token INTEGER, lease_expires_at TEXT,
      next_attempt_at TEXT, error_class TEXT, error_message TEXT, cost_usd REAL,
      UNIQUE(step, item_id, generation))
staged_outputs(delivery_id TEXT, attempt INTEGER, seq INTEGER, key TEXT, payload TEXT, PRIMARY KEY(delivery_id, attempt, seq))
dead_letters(id TEXT PRIMARY KEY, pipeline TEXT, run_id TEXT, origin_delivery TEXT, kind TEXT, state TEXT,
      stream TEXT, created_at TEXT)
events(seq INTEGER PRIMARY KEY, ts TEXT, pipeline TEXT, run_id TEXT, kind TEXT, data TEXT)
generations(pipeline TEXT PRIMARY KEY, next INTEGER)
```

Delivery ids: `dl_` + 32 hex of `hash(step, item_id, generation)`. Run ids for cron:
`run_<scheduledAt RFC3339 minute>_<trigger>`; for manual: `run_<request id>_<trigger>`.

## Interfaces (shared across tasks)

```go
// internal/pipeline
type Pipeline struct {
    Name, Description string
    Vars     map[string]any            // defaults; nil default means required
    Secrets  []string
    Triggers map[string]Trigger
    Streams  map[string]StreamDecl
    Steps    map[string]Step
    Budget   Budget
    Limits   Limits
}
type Trigger struct { Cron *CronSpec; Manual *ManualSpec; Webhook *WebhookSpec }
type CronSpec struct { Expr, TZ, Catchup string }               // catchup: latest|all|none
type Step struct {
    Name, Action string
    In  []string
    Out Out
    DLQ string                         // default "<step>.dlq"
    Config map[string]any
    Concurrency int; Rate string; Retry Retry; Timeout time.Duration; Paused bool
}
type Out struct { Streams []string; Routes []Route }             // exactly one non-empty, or both empty (terminal)
type Route struct { When, Out string }
type Package struct { Dir string; Pipeline *Pipeline; Hash string; Files map[string][]byte }
func Load(dir string) (*Package, error)
func ResolveVars(p *Pipeline, flags map[string]string, env func(string) (string, bool)) (Resolved, error)
type Resolved struct { Vars map[string]any; Sources map[string]string; Secrets map[string]string }
type Diagnostic struct { Severity, Path, Message string }     // severity: error|warning
func Check(pkg *Package, actions ActionResolver) []Diagnostic
func Graph(p *Pipeline, format string) (string, error)        // mermaid|dot

// internal/store
type Store interface {
    Close() error
    ApplyRevision(ctx context.Context, pkg PackageRecord) (RevisionID, error)
    Fire(ctx context.Context, f Firing) (runID string, created bool, err error)          // Trigger unit
    Lease(ctx context.Context, req LeaseRequest) ([]Lease, error)                         // Lease unit
    Renew(ctx context.Context, owner string, leases []LeaseRef, ttl time.Duration) error
    Done(ctx context.Context, d DoneRequest) error                                        // Done unit
    Fail(ctx context.Context, f FailRequest) error                                        // Fail unit
    Cancel(ctx context.Context, runID string) error                                       // Cancel unit
    ReplayDeadLetters(ctx context.Context, runID string, ids []string, migrate bool) error
    DiscardDeadLetters(ctx context.Context, ids []string) error
    ExpireLeases(ctx context.Context) (int, error)
    // reads
    Runs(ctx context.Context, f RunFilter) ([]Run, error)
    Items(ctx context.Context, f ItemFilter) ([]Item, error)
    DeadLetters(ctx context.Context, f DLFilter) ([]DeadLetter, error)
    Events(ctx context.Context, afterSeq int64, limit int) ([]Event, error)
    SetPaused(ctx context.Context, pipeline, step string, paused bool) error
}
func OpenSQLite(path string, opts Options) (Store, error)   // ":memory:" for tests
```

### Task 2: pipeline model, packages, vars and secrets, graph

**Files:** `internal/pipeline/*.go` and tests; `internal/ids/*.go`.

- [ ] Parse `pipeline.yaml` (or a lone file) into `Pipeline`, with unknown-key errors carrying a YAML path.
      `out` accepts a string, a list of strings, or a list of `{when, out}`; mixing is an error. `dlq` defaults to
      `<step>.dlq`. Trigger kinds: cron, manual, webhook (webhook only parsed in M1). `in` required.
- [ ] `Load(dir)`: read every regular file (skip `.git`, `.millstream`), sort paths, hash `path\0content\0` with
      SHA-256 → `Package.Hash`.
- [ ] `ResolveVars`: precedence `--var` > `MILLSTREAM_VAR_<UPPER_SNAKE>` > default; JSON parse unless the default is a
      string; type must match; `null` default = required. Secrets from `MILLSTREAM_SECRET_<UPPER_SNAKE>` (no
      environment file in M1). `Sources` records `flag|env|default`.
- [ ] `ids`: item, trigger item, delivery, dead letter, run ids, `UpperSnake("homesiteToken") == "HOMESITE_TOKEN"`.
- [ ] `Graph`: Mermaid `flowchart LR` and DOT, steps as nodes, streams as labelled edges.
- [ ] Tests: table tests for every `out` shape and mixing error; package hash stable across file order and changed by
      any byte; var precedence, typing errors, required var; id formulas against golden values; graph golden files.

### Task 6: protocol, Go SDK, protocol document

**Files:** `internal/protocol/*.go`, `sdk/go/{go.mod,millstream.go,millstream_test.go}`, `docs/protocol.md`.

- [ ] Messages: engine→action `hello`, `item`, `shutdown`; action→engine `ready`, `emit`, `metric`, `done`, `error`.
      Framing: one JSON object per line, max line 8 MiB, unknown `type` = protocol violation.
- [ ] SDK: `Map[In, Out any](fn func(Context, In) ([]Out, error))` for zero or one output (more is an error unless
      keyed), `MapKeyed[In, Out](fn func(Context, In) ([]Keyed[Out], error))`; `Context` gives `Config()`, `Vars()`,
      `Metric(name, value, labels)`, `Logger()` (slog to stderr); a returned error with `Retryable(err)` sends
      `retryable: true`.
- [ ] `docs/protocol.md`: the minimal protocol (messages, ordering, rules from spec 6.3), linked from the spec.
- [ ] Tests: framing round trips, oversized line, SDK end to end over pipes.

### Task 7: store and writer loop

**Files:** `internal/store/*.go`, `internal/store/sqlite/*.go`, `internal/failpoint/*.go`.

- [ ] SQLite opened with WAL, one write connection owned by the writer goroutine, a read pool; migrations at open.
- [ ] Writer loop: requests on a channel, batched into one transaction (max 64 units or 5 ms), each unit applied
      whole; events appended with `seq` assigned in commit order.
- [ ] Units (spec 5.11) for M1: Trigger (insert run + trigger item under deterministic ids, conflict = no-op, create
      deliveries for steps reading `trigger.<name>`), Lease (pick oldest pending of unpaused steps within concurrency,
      set owner, new fencing token, expiry = now + ttl), Renew, Done (fencing check; key rule; route staged outputs:
      CEL `when` first-match, unmatched → `unrouted` dead letter; first-commit rule with `nondeterministicOutput`
      event; create consumer deliveries; mark done; for a cancelled run discard and mark cancelled), Fail (retry with
      exponential backoff and jitter, or dead + dead letter item on the dlq stream), Cancel, Dead-letter replay
      (`dead` delivery → pending with attempts reset; `unrouted` → route stored output), Dead-letter discard,
      ExpireLeases (expired leased → pending).
- [ ] Run settlement after each unit: settled when every delivery is terminal → `succeeded` or
      `completedWithErrors` (open or discarded dead letters); `waitingReview` reserved for M3.
- [ ] `failpoint.Hit(name)`: when `MILLSTREAM_FAILPOINT=<name>` is set, `os.Exit(137)`; called before and after each
      unit's commit (`<unit>.beforeCommit`, `<unit>.afterCommit`).
- [ ] Tests: each unit's happy path and conflicts; stale fencing token refused; key rule violation; first-commit
      no-op and conflict; routing first match and unrouted; backoff schedule; cancel during lease; settlement states;
      events gap-free and ordered; property test of random unit sequences checking invariants (no delivery in two
      states, every item has its consumer deliveries, settled runs have only terminal deliveries).

### Task 8: exec runtime and embedded node

**Files:** `internal/runtime/exec/*.go`, `internal/node/*.go`.

- [ ] Exec runtime: start the action's command with `MILLSTREAM_WORKDIR` (per-delivery temp dir) and stdio pipes;
      send `hello`, await `ready` (10 s); per delivery send `item`, collect `emit`/`metric`, finish on `done` or
      `error`; stderr lines re-emitted via slog with keys; long-lived processes reused only for the same action
      digest, config and vars; per-item processes for `lifecycle: perItem`; timeout kills the process (retryable).
- [ ] Node: pull loop over an in-memory transport to the engine (`Transport` interface: `Pull(n) []Delivery`,
      `Heartbeat(leases)`, `Done`, `Fail`), heartbeat every 5 s renewing all leases (ttl 60 s, configurable for
      tests), fencing token carried on every message, graceful drain on context cancel.
- [ ] Tests with a fake action (a Go test binary built in `TestMain`): normal emit/done, multiple keyed outputs, crash
      mid-delivery, garbage line, timeout, stderr re-emitted with keys, no payload in logs.

### Task 9: engine

**Files:** `internal/engine/*.go`.

- [ ] Scheduler: cron triggers (robfig/cron with seconds disabled, timezone), catchup on start from the last fired
      time recorded in events (`latest|all|none`), manual `Fire`.
- [ ] Dispatcher: serves the node transport by calling `Store.Lease`, round-robin across pipelines, respects step
      `concurrency`, pipeline `limits.concurrency`, step `rate` (token bucket, in memory), pause state.
- [ ] Per-run vars resolution at run start (stored on the run); config interpolation per step at dispatch from the
      run's vars (never `item`).
- [ ] Lease expiry ticker; settlement; replay of dead letters; cancel.
- [ ] Tests: cron catchup modes with a fake clock; round-robin fairness; concurrency and rate limits; pause/resume;
      vars stored per run; config interpolation.

### Task 10: CLI commands

**Files:** `internal/cli/*.go`.

- [ ] `run [dir…] [--var k=v] [--once] [--db path]`: apply each package as a revision, start engine + embedded node,
      `--once` fires each manual trigger (or the first cron) once and exits when every run settles (exit 0 if all
      succeeded, 1 otherwise). Default db `.millstream/millstream.db`.
- [ ] `status`, `tail` (events stream), `trigger <pipeline> <trigger>`, `cancel <run>`, `replay --from dlq --run <id>
      [--migrate]`, `dlq list|discard`, `pause|resume <pipeline> [step]`, `vars`, all against `--db`.
- [ ] `test pipeline [dir]`: runs the package on in-memory SQLite with stubbed actions declared in
      `tests/*.yaml` (`stub: {step: outputs}`) and asserts stream contents (`expect: {stream: count | items}`).
- [ ] Tests through the parser for every command.

### Task 11: M1 fixture, end to end and crash suite

**Files:** `examples/m1-fixture/**`, `internal/e2e/*_test.go`.

- [ ] Fixture: the reference pipeline's shape with exec actions built from the SDK: `crawl` (emits 50 keyed
      listings deterministically from its config seed), `score` (deterministic score), `rentability`, `report`
      (writes a small text artifact path in payload); routes and a `dlq`; one listing designed to fail
      non-retryably (dead letter).
- [ ] E2E: `millstream run --once` on the fixture; assert counts per stream, one dead letter, run state
      `completedWithErrors`; replay of the dead letter after a revision fix with `--migrate` reaches `succeeded`.
- [ ] Crash suite: for every failpoint of every M1 unit, run the fixture with `MILLSTREAM_FAILPOINT` set, then rerun
      without it on the same database; assert: no item lost (final stream counts equal the clean run), no output
      published twice (item ids unique, no duplicate keys per stream), every run settles. Plus 20 seeded random
      `kill -9` points.
